# Administration API

These read-only operational contracts expose safe summaries, never secrets, payloads, full prompts,
provider tokens, topology, SQL, or configuration values. All require bearer auth and `admin:read`.
Workspace is optional for system-wide authorized administrators: when supplied, `X-Workspace-ID`
restricts results and membership/administrative scope is validated. Rate is 60/min/principal.

| Operation              | Complete contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `listAdminJobs`        | **Purpose:** inspect safe background and publishing job projections. **Route:** `GET /api/v1/admin/jobs`. **Headers:** bearer; optional workspace. **Query:** cursor/limit; repeated `state`,`queueName`; `jobType`,`resourceType`,`resourceId`; `createdAfter`,`createdBefore`; sort `updatedAt                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | -updatedAt | createdAt    | -createdAt`, default `-updatedAt`. **Body:** none. **Response:** `200 PagedResponse<Job>`. **Validation:** allowlists/UUIDs/cursor; global access requires explicit administrative grant. **Statuses/errors:** `200`; standard. **Idempotency:** inherent. **Example:** `?state=failed&queueName=ai` → paged jobs envelope. |
| `listAdminQueues`      | **Purpose:** retrieve aggregate queue depth/age/terminal counts. **Route:** `GET /api/v1/admin/queues`. **Headers:** bearer; optional workspace. **Query:** repeated `queueName` from `ai                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | media      | notification | maintenance                                                                                                                                                                                                                                                                                                                 | publishing`. **Body:** none. **Response:** `200 Success<QueueSummary[]>`. **Validation:** queue allowlist and scope. **Statuses/errors:** `200`; standard plus `503 dependency_unavailable`. **Idempotency:** inherent. **Example:** `GET /api/v1/admin/queues`→`{"success":true,"message":"Queue summaries retrieved.","data":[{"queueName":"ai","queued":3,"running":1,"retryWait":0,"failed":0,"deadLettered":0,"oldestQueuedAt":"2026-08-02T11:00:00Z"}],"meta":{"requestId":"req_queues"}}`. |
| `listAdminProviders`   | **Purpose:** inspect normalized AI/social/storage/notification provider status. **Route:** `GET /api/v1/admin/providers`. **Headers:** bearer; optional workspace. **Query:** repeated `providerType`; optional `status`. **Body:** none. **Response:** `200 Success<ProviderStatus[]>`; no credential/config detail. **Validation:** enum allowlists. **Statuses/errors:** `200`; standard. **Idempotency:** inherent. **Example:** `?providerType=ai` → provider status array envelope.                                                                                                                                                                                                                                                                                                       |
| `getAdminSystemStatus` | **Purpose:** retrieve authenticated operational system/dependency summary. **Route:** `GET /api/v1/admin/system`. **Headers:** bearer; workspace not required. **Path/query/body:** none. **Response:** `200 Success<SystemStatus>`; degraded dependencies may still return `200` with status `degraded`; `503 dependency_unavailable` only when the status service cannot produce a trustworthy result. **Validation:** admin scope. **Statuses/errors:** `200`; standard plus `503`. **Idempotency:** inherent. **Example:** `GET /api/v1/admin/system` → `{"success":true,"message":"System status retrieved.","data":{"status":"healthy","version":"1.0.0","startedAt":"2026-08-02T00:00:00Z","dependencies":[{"name":"database","status":"healthy"}]},"meta":{"requestId":"req_system"}}`. |
