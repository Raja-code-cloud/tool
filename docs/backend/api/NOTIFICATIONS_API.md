# Notifications API

All routes require bearer auth and `X-Workspace-ID`. Notifications are recipient-scoped and
non-disclosable across users/workspaces.

| Operation              | Complete contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `listNotifications`    | **Purpose:** list the current user's notification inbox. **Route:** `GET /api/v1/notifications`. **Auth/permission:** `notifications:read`. **Headers:** bearer/workspace. **Query:** cursor/limit; `q`; repeated `severity`,`typeCode`; `read` boolean; `createdAfter`,`createdBefore`; sort `createdAt                                                                                                                                                                                                                                                                                                                        | -createdAt | updatedAt | -updatedAt`, default `-updatedAt`. **Body:** none. **Response:** `200 PagedResponse<Notification>`. **Validation:** strict booleans/enums/ranges/cursor. **Statuses/errors:** `200`; standard. **Rate:** read 120/min. **Idempotency:** inherent. **Example:** `?read=false&limit=25`→`{"success":true,"message":"Notifications retrieved.","data":[],"meta":{"requestId":"req_notifications","page":{"nextCursor":null,"hasMore":false,"limit":25}}}`. |
| `markNotificationRead` | **Purpose:** set or clear read state. **Route:** `PATCH /api/v1/notifications/{id}/read`. **Auth/permission:** `notifications:write`. **Headers:** bearer/workspace, JSON, required `If-Match`. **Path:** notification UUID. **Query:** none. **Body:** `{read:boolean}`. **Response:** `200 Success<Notification>` with ETag. **Validation:** exact body and recipient ownership. **Statuses/errors:** `200`; standard plus `409 version_conflict`. **Rate:** write 60/min. **Idempotency:** setting the same value is semantic idempotency. **Example:** `{"read":true}` → Notification with `readAt:"2026-08-02T12:00:00Z"`. |
| `deleteNotification`   | **Purpose:** archive/soft-delete a user-visible notification; delivery/audit evidence remains by policy. **Route:** `DELETE /api/v1/notifications/{id}`. **Auth/permission:** `notifications:delete`. **Headers:** bearer/workspace, required `If-Match`. **Path:** UUID. **Query/body:** none. **Response:** `204`. **Validation:** recipient ownership/latest version. **Statuses/errors:** `204`; standard plus `409 version_conflict`. **Rate:** write 60/min. **Idempotency:** semantic; deleted item becomes non-disclosable. **Example:** delete with matching ETag → `204`.                                             |
