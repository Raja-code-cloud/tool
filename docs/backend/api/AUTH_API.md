# Authentication API

Base path `/api/v1`. See [`API_OVERVIEW.md`](API_OVERVIEW.md) for envelopes, shared headers, errors,
and rate headers; DTOs are in [`COMMON_SCHEMAS.md`](COMMON_SCHEMAS.md). OAuth authorization uses
provider `authorizationUrl`, state, nonce, and PKCE. The provider callback is deployment-registered
(recommended `GET /api/v1/auth/callback/{provider}`), validates state/code/redirect URI, binds the
identity, creates the application session, and redirects without tokens in the URL. It is an OAuth
integration callback, not an additional frontend REST operation in this requested registry.

Browser clients receive a rotated refresh token as a `Secure; HttpOnly; SameSite=Lax` cookie scoped
to `/api/v1/auth`; non-browser confidential clients may receive `refreshToken` in the login response
only when explicitly registered. Refresh bodies never accept both transports. Cookie refresh/logout
requires the approved CSRF header.

| Operation            | Complete contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `login`              | **Purpose:** establish a session through registered local/OIDC exchange. **Method/route:** `POST /api/v1/auth/login`. **Auth/permission:** public. **Headers:** `Content-Type: application/json`; optional `X-Request-ID`; `Idempotency-Key` not used. **Path/query:** none. **Body:** `{providerCode:string, authorizationCode?:string, codeVerifier?:string, redirectUri?:uri, email?:email, password?:string}`; provider-specific fields are mutually exclusive. **Response:** `200 Success<Session>` and refresh cookie/registered confidential token. **Validation:** known enabled provider, exact redirect URI, PKCE when required; email/password only for a configured local provider. **Statuses/errors:** `200`; `400 invalid_request`; `401 invalid_credentials`; `429 rate_limited`; `503 dependency_unavailable`. **Rate:** 10/min/IP. **Idempotency:** no; repeated success creates/rotates a session. **Example:** `{"providerCode":"oidc","authorizationCode":"safe-example-code","codeVerifier":"43-character-example-verifier-value-0000000","redirectUri":"https://app.example.test/callback"}` → `{"success":true,"message":"Signed in.","data":{"user":{"id":"01900000-0000-7000-8000-000000000001","version":1,"createdAt":"2026-08-01T00:00:00Z","updatedAt":"2026-08-02T10:00:00Z","email":"user@example.test","displayName":"Example User","locale":"en","timeZone":"UTC","status":"active"},"scopes":["profile:read"],"workspaceIds":[],"access":{"accessToken":"<redacted>","tokenType":"Bearer","expiresIn":900}},"meta":{"requestId":"req_login"}}`. |
| `logout`             | **Purpose:** revoke the current refresh session and clear cookie. **Method/route:** `POST /api/v1/auth/logout`. **Auth/permission:** bearer or refresh session; no workspace permission. **Headers:** bearer or refresh cookie; CSRF header for cookie; no body. **Path/query:** none. **Response:** `204`, no envelope/body; clears cookie. **Validation:** session transport must be unambiguous. **Statuses/errors:** `204`; `400 invalid_request`; `401 authentication_required`; `429 rate_limited`. **Rate:** write 60/min/principal. **Idempotency:** semantic idempotency; an already-revoked current session still returns `204`. **Example:** `POST /api/v1/auth/logout` with refresh cookie → `204 No Content`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `refreshAccessToken` | **Purpose:** rotate refresh session and issue access token. **Method/route:** `POST /api/v1/auth/refresh`. **Auth/permission:** valid refresh token; no bearer required. **Headers:** refresh cookie plus CSRF, or registered client token transport; JSON body only for `{refreshToken:string}` in that transport. **Path/query:** none. **Response:** `200 Success<AuthTokens>`, rotated refresh token/cookie. **Validation:** one transport, rotation/reuse detection, active user/session. **Statuses/errors:** `200`; `400 invalid_request`; `401 refresh_token_invalid`; `429 rate_limited`; `503 dependency_unavailable`. **Rate:** 30/min/principal (IP fallback before resolution). **Idempotency:** no; token rotates once. **Example:** `{}` with cookie → `{"success":true,"message":"Access token refreshed.","data":{"accessToken":"<redacted>","tokenType":"Bearer","expiresIn":900},"meta":{"requestId":"req_refresh"}}`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `getCurrentSession`  | **Purpose:** return resolved principal, permissions, and workspaces. **Method/route:** `GET /api/v1/auth/me`. **Auth/permission:** bearer; no workspace permission. **Headers:** `Authorization`. **Path/query/body:** none. **Response:** `200 Success<Session>`. **Validation:** active, non-revoked token/session. **Statuses/errors:** `200`; `401 invalid_token`; `429 rate_limited`. **Rate:** read 120/min/principal. **Idempotency:** inherent. **Example:** `GET /api/v1/auth/me` → `{"success":true,"message":"Session retrieved.","data":{"user":{"id":"01900000-0000-7000-8000-000000000001","version":1,"createdAt":"2026-08-01T00:00:00Z","updatedAt":"2026-08-02T10:00:00Z","email":"user@example.test","displayName":"Example User","locale":"en","timeZone":"UTC","status":"active"},"scopes":["profile:read"],"workspaceIds":["01900000-0000-7000-8000-000000000010"]},"meta":{"requestId":"req_me"}}`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `listAuthProviders`  | **Purpose:** list enabled sign-in providers without secrets. **Method/route:** `GET /api/v1/auth/providers`. **Auth/permission:** public. **Headers:** optional `If-None-Match`. **Path/query/body:** none. **Response:** `200 Success<AuthProvider[]>` or `304`; private credentials excluded. **Validation:** none. **Statuses/errors:** `200`, `304`; `429 rate_limited`; `503 dependency_unavailable`. **Rate:** public-read deployment policy, default 120/min/IP. **Idempotency:** inherent. **Example:** `GET /api/v1/auth/providers` → `{"success":true,"message":"Authentication providers retrieved.","data":[{"code":"oidc","name":"Company SSO","authorizationUrl":"https://identity.example.test/authorize","pkceRequired":true}],"meta":{"requestId":"req_providers"}}`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
