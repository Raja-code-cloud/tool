# Publishing API

All routes require bearer auth and `X-Workspace-ID`. A publication binds an asset to an immutable
content version; dispatch rechecks approval and connected account health.

| Operation                | Complete contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `createPublication`      | **Purpose:** create a publication and targets from content without dispatching it. **Route:** `POST /api/v1/publish`. **Auth/permission:** `publishing:write`. **Headers:** bearer, workspace, JSON, required `Idempotency-Key`. **Path/query:** none. **Body:** `CreatePublicationRequest`. **Response:** `201 Success<Publication>`, `Location`, ETag. **Validation:** approved immutable version, asset/version relationship, nonempty unique healthy account targets in workspace, provider capability. **Statuses/errors:** `201`; standard plus `409 approval_required                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | social_account_unhealthy                                                                                                                                                                                                                                                                                                                                                                                                | idempotency_conflict`. **Rate:** publish 30/min. **Idempotency:** required. **Example:** `{"contentId":"01900000-0000-7000-8000-000000000401","contentVersionId":"01900000-0000-7000-8000-000000000402","title":"Launch","targets":[{"socialAccountId":"01900000-0000-7000-8000-000000000403"}]}` → Publication success envelope. |
| `dispatchPublication`    | **Purpose:** asynchronously dispatch an existing ready publication. **Route:** `POST /api/v1/publish/{id}`. **Auth/permission:** `publishing:write`. **Headers:** bearer, workspace, required `If-Match` and `Idempotency-Key`; JSON. **Path:** publication UUID. **Query:** none. **Body:** `{targetIds?:Uuid[]}`; absent means all eligible targets. **Response:** `202 Success<Operation>` with `Location`. **Validation:** publication ready, targets approved, accounts enabled/healthy, no active duplicate job. **Statuses/errors:** `202`; standard plus approval/account/state/provider errors. **Rate:** publish 30/min. **Idempotency:** required; replay returns same operation. **Example:** `{"targetIds":["01900000-0000-7000-8000-000000000404"]}` → `{"success":true,"message":"Publication dispatch accepted.","data":{"id":"01900000-0000-7000-8000-000000000405","type":"publishing","status":"queued","resourceType":"publication","resourceId":"01900000-0000-7000-8000-000000000406","createdAt":"2026-08-02T12:00:00Z","updatedAt":"2026-08-02T12:00:00Z"},"meta":{"requestId":"req_publish"}}`. |
| `listPublicationHistory` | **Purpose:** list publication/target status event projections. **Route:** `GET /api/v1/publish/history`. **Auth/permission:** `publishing:read`. **Headers:** bearer, workspace. **Query:** cursor/limit; `occurredAfter`, `occurredBefore`; repeated `state`; `contentId`, `platformId`, `socialAccountId`; sort only `occurredAt                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | -occurredAt`, default `-occurredAt`. **Body:** none. **Response:** `200 PagedResponse<PublicationHistoryItem>`where item is`{id,publicationId,targetId,stateType,fromState,toState,reasonCode?,occurredAt}`. **Validation:** allowlists/UUIDs/range/cursor. **Statuses/errors:** `200`; standard. **Rate:** read 120/min. **Idempotency:** inherent. **Example:** `?state=completed&limit=25` → paged history envelope. |
| `cancelPublication`      | **Purpose:** cancel a publication and cancelable pending jobs; this is not hard deletion and cannot retract already published external posts. **Route:** `DELETE /api/v1/publish/{id}`. **Auth/permission:** `publishing:delete`. **Headers:** bearer, workspace, required `If-Match`. **Path:** UUID. **Query/body:** none. **Response:** `200 Success<Publication>` with status `cancelled` and ETag; asynchronous provider work already running may settle before cancellation. **Validation:** only draft/ready/in-progress cancelable portions; completed remains retained. **Statuses/errors:** `200`; standard plus state/version conflicts. **Rate:** publish 30/min. **Idempotency:** semantic; already cancelled returns current `200`. **Example:** delete with matching ETag → cancelled Publication envelope.                                                                                                                                                                                                                                                                                               |
