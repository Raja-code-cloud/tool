# Analytics API

All routes require bearer auth, `analytics:read`, and `X-Workspace-ID`. Rate limit is
60/min/principal/workspace. Decimal metrics are strings and include units/methodology freshness.

| Operation                | Complete contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `getAnalyticsDashboard`  | **Purpose:** retrieve workspace KPI dashboard. **Route:** `GET /api/v1/analytics/dashboard`. **Headers:** auth/workspace. **Query:** required `periodStart`,`periodEnd` RFC 3339; optional `timeZone` (workspace default), repeated `metric`, `platformId`; max range 366 days. **Body:** none. **Response:** `200 Success<AnalyticsDashboard>`. **Validation:** ordered range, IANA zone, known metrics/platforms. **Statuses/errors:** `200`; standard plus `422 validation_failed`, `503 dependency_unavailable`. **Idempotency:** inherent. **Example:** `?periodStart=2026-07-01T00:00:00Z&periodEnd=2026-08-01T00:00:00Z` → `{"success":true,"message":"Dashboard retrieved.","data":{"periodStart":"2026-07-01T00:00:00Z","periodEnd":"2026-08-01T00:00:00Z","timeZone":"UTC","freshThrough":"2026-08-01T23:00:00Z","methodologyVersion":1,"metrics":[{"code":"reach","value":"1200","unit":"count","isEstimated":false}]},"meta":{"requestId":"req_dashboard"}}`. |
| `listAnalyticsPosts`     | **Purpose:** rank post/content performance. **Route:** `GET /api/v1/analytics/posts`. **Headers:** auth/workspace. **Query:** cursor/limit; period range; `platformId`,`socialAccountId`; sort allowlist `reach,engagements,clicks,conversions,engagementRate,snapshotAt` with leading minus, default `-snapshotAt`. **Body:** none. **Response:** `200 PagedResponse<PostPerformance>`. **Validation:** range/UUID/sort/cursor. **Statuses/errors:** `200`; standard. **Idempotency:** inherent. **Example:** `?sort=-engagementRate&limit=25` → paged post performance envelope.                                                                                                                                                                                                                                                                                                                                                                                        |
| `listAnalyticsPlatforms` | **Purpose:** compare platform/account aggregates. **Route:** `GET /api/v1/analytics/platforms`. **Headers:** auth/workspace. **Query:** period range; repeated `platformId`; repeated `metric`; `sort` allowlist `platformCode,-platformCode`. **Body:** none. **Response:** `200 Success<PlatformAnalytics[]>`. **Validation:** known platform/metrics and max range. **Statuses/errors:** `200`; standard. **Idempotency:** inherent. **Example:** request period → platform analytics array envelope.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `getAnalyticsPost`       | **Purpose:** retrieve one content/post performance projection. **Route:** `GET /api/v1/analytics/post/{id}`. **Headers:** auth/workspace, optional `If-None-Match`. **Path:** content asset UUID. **Query:** optional `publicationTargetId`, required or defaulted period range (default trailing 30 days), optional repeated `metric`. **Body:** none. **Response:** `200 Success<PostPerformance>` or `304`; ETag represents snapshot identity. **Validation:** tenant-safe content/target relationship, range/metrics. **Statuses/errors:** `200`, `304`; standard including `404`. **Idempotency:** inherent. **Example:** `GET .../post/019...601?periodStart=...&periodEnd=...` → PostPerformance envelope.                                                                                                                                                                                                                                                         |
