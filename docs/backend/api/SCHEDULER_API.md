# Scheduler API

All routes require bearer auth and `X-Workspace-ID`. Scheduling preserves the requested wall time,
IANA zone, fold/policy, and resolved UTC instant. Nonexistent local times return
`422 schedule_time_nonexistent`; ambiguous times without an explicit resolution return
`409 schedule_time_ambiguous`.

| Operation        | Complete contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `createSchedule` | **Purpose:** schedule an approved publication target. **Route:** `POST /api/v1/schedule`. **Auth/permission:** `schedule:write`. **Headers:** bearer, workspace, JSON, required `Idempotency-Key`. **Path/query:** none. **Body:** `ScheduleRequest` with required `publicationTargetId`, `requestedLocalAt`, `timeZone`; `fold`/`ambiguityPolicy` as needed. **Response:** `201 Success<Schedule>`, `Location`, ETag. **Validation:** IANA zone, future resolved instant, DST rules, approved immutable target, healthy enabled account, one active schedule/target. **Statuses/errors:** `201`; standard plus schedule, approval, account and idempotency conflicts. **Rate:** write 60/min. **Idempotency:** required. **Example:** `{"publicationTargetId":"01900000-0000-7000-8000-000000000501","requestedLocalAt":"2026-11-01T01:30:00","timeZone":"America/New_York","fold":1,"ambiguityPolicy":"later","priority":"normal"}` → Schedule envelope including resolved `scheduledFor`. |
| `getSchedule`    | **Purpose:** retrieve one schedule. **Route:** `GET /api/v1/schedule/{id}`. **Auth/permission:** `schedule:read`. **Headers:** bearer, workspace, optional `If-None-Match`. **Path:** UUID. **Query/body:** none. **Response:** `200 Success<Schedule>` with ETag or `304`. **Validation:** active tenant-safe lookup. **Statuses/errors:** `200`, `304`; standard. **Rate:** read 120/min. **Idempotency:** inherent. **Example:** request by ID → Schedule success envelope.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `listSchedules`  | **Purpose:** list calendar schedules. **Route:** `GET /api/v1/schedule`. **Auth/permission:** `schedule:read`. **Headers:** bearer, workspace. **Query:** cursor/limit; repeated `state`,`priority`; `publicationTargetId`; `scheduledAfter`,`scheduledBefore`; sort `scheduledFor,-scheduledFor,updatedAt,-updatedAt`, default `-updatedAt`. **Body:** none. **Response:** `200 PagedResponse<Schedule>`. **Validation:** enums/UUID/range/cursor. **Statuses/errors:** `200`; standard. **Rate:** read 120/min. **Idempotency:** inherent. **Example:** `?state=scheduled&scheduledAfter=2026-08-02T00:00:00Z` → paged schedule envelope.                                                                                                                                                                                                                                                                                                                                                  |
| `updateSchedule` | **Purpose:** reschedule or change priority/state before dispatch. **Route:** `PATCH /api/v1/schedule/{id}`. **Auth/permission:** `schedule:write`. **Headers:** bearer, workspace, JSON, required `If-Match`. **Path:** UUID. **Query:** none. **Body:** nonempty subset of `{requestedLocalAt,timeZone,fold,ambiguityPolicy,priority,state:"scheduled"                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | "paused"}`; changing wall time or zone recomputes `scheduledFor`. **Response:** `200 Success<Schedule>`with ETag. **Validation:** full DST and target invariants; dispatched/terminal schedules cannot be rescheduled. **Statuses/errors:**`200`; standard plus schedule/state/version conflicts. **Rate:** write 60/min. **Idempotency:** identical PATCH/version is idempotent. **Example:** `{"requestedLocalAt":"2026-08-05T09:00:00","timeZone":"Europe/Paris","ambiguityPolicy":"reject"}` → updated Schedule. |
| `cancelSchedule` | **Purpose:** cancel, not hard-delete, a schedule and prevent future dispatch. **Route:** `DELETE /api/v1/schedule/{id}`. **Auth/permission:** `schedule:delete`. **Headers:** bearer, workspace, required `If-Match`. **Path:** UUID. **Query/body:** none. **Response:** `200 Success<Schedule>` with state `cancelled` and ETag. **Validation:** draft/scheduled/paused only; dispatched jobs use publication cancellation. **Statuses/errors:** `200`; standard plus state/version conflicts. **Rate:** write 60/min. **Idempotency:** semantic; already cancelled returns current representation. **Example:** delete with matching ETag → cancelled Schedule envelope.                                                                                                                                                                                                                                                                                                                  |
