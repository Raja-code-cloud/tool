# User API

Base `/api/v1`; global profile routes do not use `X-Workspace-ID`. Shared envelope/error/concurrency
rules are in [`API_OVERVIEW.md`](API_OVERVIEW.md).

| Operation           | Complete contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `getUserProfile`    | **Purpose:** retrieve the authenticated global profile. **Route:** `GET /api/v1/users/me`. **Auth/permission:** bearer, `profile:read`. **Headers:** `Authorization`; optional `If-None-Match`. **Path/query/body:** none. **Response:** `200 Success<User>` with `ETag`, or `304`. **Validation:** active principal. **Statuses/errors:** `200`, `304`; standard `401/403/429/500`. **Rate:** read 120/min/principal. **Idempotency:** inherent. **Example:** request `GET /api/v1/users/me`; response `{"success":true,"message":"Profile retrieved.","data":{"id":"01900000-0000-7000-8000-000000000001","version":3,"createdAt":"2026-01-01T00:00:00Z","updatedAt":"2026-08-02T10:00:00Z","email":"user@example.test","displayName":"Example User","locale":"en","timeZone":"America/New_York","status":"active"},"meta":{"requestId":"req_profile"}}`.                                                                                                                                                                                                                                                                                                      |
| `updateUserProfile` | **Purpose:** partially update safe profile fields. **Route:** `PATCH /api/v1/users/me`. **Auth/permission:** bearer, `profile:write`. **Headers:** `Authorization`, required `If-Match`, JSON. **Path/query:** none. **Body:** any nonempty subset `{displayName:string(1..120), locale:string(2..35), timeZone:IANA, avatarObjectKey?:string                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | null}`; email/status are not writable here. **Response:** `200 Success<User>`with new`ETag`. **Validation:** unknown/empty body rejected, IANA zone and locale syntax, avatar owned and clean. **Statuses/errors:** `200`; standard plus `409 version_conflict`, `422 validation_failed`. **Rate:** write 60/min/principal. **Idempotency:** PATCH is idempotent for identical body/version; no key. **Example:** `{"displayName":"Avery Example","timeZone":"Europe/Paris"}`with`If-Match: "3"`→`{"success":true,"message":"Profile updated.","data":{"id":"01900000-0000-7000-8000-000000000001","version":4,"createdAt":"2026-01-01T00:00:00Z","updatedAt":"2026-08-02T11:00:00Z","email":"user@example.test","displayName":"Avery Example","locale":"en","timeZone":"Europe/Paris","status":"active"},"meta":{"requestId":"req_update"}}`. |
| `deleteUserProfile` | **Purpose:** initiate access revocation and policy-aware anonymization/erasure; it does not erase retained audit/billing evidence immediately. **Route:** `DELETE /api/v1/users/me`. **Auth/permission:** bearer, `profile:delete`. **Headers:** `Authorization`, required `If-Match`; optional JSON confirmation body is not accepted. **Path/query/body:** none. **Response:** `202 Success<Operation>` with `Location` because revocation/erasure is asynchronous. **Validation:** legal/ownership constraints and latest version. **Statuses/errors:** `202`; standard plus `409 version_conflict`, `409 state_transition_invalid`. **Rate:** write 60/min/principal. **Idempotency:** semantic; repeated request returns the active deletion operation. **Example:** `DELETE /api/v1/users/me` with `If-Match: "4"` → `{"success":true,"message":"Profile deletion accepted.","data":{"id":"01900000-0000-7000-8000-000000000099","type":"adminJob","status":"queued","resourceType":"user","resourceId":"01900000-0000-7000-8000-000000000001","createdAt":"2026-08-02T11:05:00Z","updatedAt":"2026-08-02T11:05:00Z"},"meta":{"requestId":"req_delete"}}`. |
