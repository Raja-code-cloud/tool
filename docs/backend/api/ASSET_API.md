# Asset API

All routes use `/api/v1`, bearer auth, and required `X-Workspace-ID`. Common pagination, envelopes,
errors, ETags, and limits are in [`API_OVERVIEW.md`](API_OVERVIEW.md).

Upload and replacement use `multipart/form-data`: required `file` and `assetType`; upload additionally
requires `title`; optional `summary`, `projectId`, `folderId`, `checksumSha256` (64 lowercase hex).
Filename length is 1–255. Declared type must match detected content. Allowed pairs:

- `poster`, `thumbnail`: `image/jpeg`, `image/png`, `image/webp`, maximum 10 MiB.
- `article`: `text/plain`, `text/markdown`, `application/pdf`,
  `application/vnd.openxmlformats-officedocument.wordprocessingml.document`, maximum 25 MiB.
- `video`: `video/mp4`, `video/webm`, `video/quicktime`, maximum 2 GiB.

Malware is rejected/quarantined; client MIME and extension are never trusted.

| `uploadAsset`      | **Purpose:** create asset and ingest source file. **Route:** `POST /api/v1/assets/upload`. **Auth/permission:** `assets:write`. **Headers:** bearer, workspace, required `Idempotency-Key`, multipart. **Path/query:** none. **Body:** upload fields above. **Response:** `202 Success<Operation>` with `Location`; operation resolves to `Asset` after scan/metadata processing. **Validation:** pair/size/filename/detected MIME/checksum/malware/ownership. **Statuses/errors:** `202`; standard plus `413 payload_too_large`, `415 unsupported_media_type`, `422 checksum_mismatch                                                                                                                                                                                                                                                                                                                                                                                                                                                          | malware_detected`. **Rate:** 20/hour/principal/workspace plus byte quota. **Idempotency:** required, ≥24h replay. **Example:** multipart `assetType=poster,title=Launch,file=@launch.webp`→`{"success":true,"message":"Upload accepted.","data":{"id":"01900000-0000-7000-8000-000000000101","type":"upload","status":"queued","resourceType":"asset","createdAt":"2026-08-02T12:00:00Z","updatedAt":"2026-08-02T12:00:00Z"},"meta":{"requestId":"req_upload"}}`. |
| `listAssets`       | **Purpose:** list active assets. **Route:** `GET /api/v1/assets`. **Auth/permission:** `assets:read`. **Headers:** bearer, workspace. **Query:** common cursor fields plus repeated `assetType`, `lifecycleStatus`, `ownerId`, `projectId`, `folderId`; sort allowlist `updatedAt,createdAt,title` default `-updatedAt`. **Body:** none. **Response:** `200 PagedResponse<Asset>`. **Validation:** UUIDs/enums/ranges. **Statuses/errors:** `200`; standard. **Rate:** read 120/min. **Idempotency:** inherent. **Example:** `?assetType=video&limit=25` → `{"success":true,"message":"Assets retrieved.","data":[],"meta":{"requestId":"req_assets","page":{"nextCursor":null,"hasMore":false,"limit":25}}}`.                                                                                                                                                                                                                                                                                                                                  |
| `getAsset`         | **Purpose:** retrieve one active asset and safe short-lived media link when clean. **Route:** `GET /api/v1/assets/{id}`. **Auth/permission:** `assets:read`. **Headers:** bearer, workspace, optional `If-None-Match`. **Path:** `id` UUID. **Query/body:** none. **Response:** `200 Success<Asset>` with `ETag`, or `304`. **Validation:** UUID and tenant-safe active lookup. **Statuses/errors:** `200`, `304`; standard including `404`. **Rate:** read 120/min. **Idempotency:** inherent. **Example:** `GET .../assets/019...201` → `{"success":true,"message":"Asset retrieved.","data":{"id":"01900000-0000-7000-8000-000000000201","version":2,"createdAt":"2026-08-01T00:00:00Z","updatedAt":"2026-08-02T00:00:00Z","assetType":"poster","title":"Launch","summary":null,"lifecycleStatus":"active","ownerId":null,"isFavorite":false,"media":{"mimeType":"image/webp","byteSize":2048,"checksumSha256":"aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa","scanStatus":"clean"}},"meta":{"requestId":"req_asset"}}`. |
| `deleteAsset`      | **Purpose:** soft-delete the content aggregate; retained versions/publications and external posts follow policy. **Route:** `DELETE /api/v1/assets/{id}`. **Auth/permission:** `assets:delete`. **Headers:** bearer, workspace, required `If-Match`. **Path:** UUID. **Query/body:** none. **Response:** `204`. **Validation:** latest version and deletion invariants. **Statuses/errors:** `204`; standard plus `409 version_conflict                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | state_transition_invalid`. **Rate:** write 60/min. **Idempotency:** semantic; inaccessible after deletion. **Example:** `DELETE .../assets/019...201`with`If-Match: "2"`→`204`.                                                                                                                                                                                                                                                                                   |
| `replaceAssetFile` | **Purpose:** replace the current source attachment while preserving asset identity/history. **Route:** `POST /api/v1/assets/{id}/replace`. **Auth/permission:** `assets:write`. **Headers:** bearer, workspace, `If-Match`, `Idempotency-Key`, multipart. **Path:** UUID. **Query:** none. **Body:** `file`, optional `checksumSha256`; existing `assetType` determines allowed pair. **Response:** `202 Success<Operation>` and `Location`; final asset increments version. **Validation:** upload rules and replacement allowed only for active mutable asset. **Statuses/errors:** `202`; standard plus upload errors and conflicts. **Rate:** upload 20/hour plus bytes. **Idempotency:** required. **Example:** multipart `file=@replacement.webp` → accepted `Operation` with `resourceId` equal to asset ID.                                                                                                                                                                                                                             |
| `searchAssets`     | **Purpose:** full-text search with structured filters. **Route:** `GET /api/v1/assets/search`. **Auth/permission:** `assets:read`. **Headers:** bearer, workspace. **Query:** required `q` length 2..200; common cursor; repeated `assetType`,`lifecycleStatus`; sort `relevance                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | -updatedAt                                                                                                                                                                                                                                                                                                                                                                                                                                                        | updatedAt`, default `relevance`then`id`. **Body:** none. **Response:** `200 PagedResponse<Asset>`; no expensive total. **Validation:** normalized safe query, filters, cursor fingerprint. **Statuses/errors:** `200`; standard plus `400 invalid_request`. **Rate:** read 120/min. **Idempotency:** inherent. **Example:** `?q=launch&assetType=poster` → paged asset envelope. |
