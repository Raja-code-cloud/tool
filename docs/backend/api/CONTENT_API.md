# Content API

All routes require bearer auth and `X-Workspace-ID`. DTOs, standard failures, pagination,
concurrency, and idempotency are defined in [`COMMON_SCHEMAS.md`](COMMON_SCHEMAS.md) and
[`API_OVERVIEW.md`](API_OVERVIEW.md).

| Operation           | Complete contract                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `generateContent`   | **Purpose:** asynchronously generate candidates from an immutable source version. **Route:** `POST /api/v1/content/generate`. **Auth/permission:** `content:generate`. **Headers:** bearer, workspace, JSON, required `Idempotency-Key`. **Path/query:** none. **Body:** `GenerationRequest`. **Response:** `202 Success<Operation>` with `Location`; generated output is immutable and acceptance creates a version. **Validation:** tenant-safe IDs, enabled model/template, source belongs asset, scope/parameter limits, quota/safety policy. **Statuses/errors:** `202`; standard plus `429 quota_exceeded`, `503 provider_unavailable`. **Rate:** AI 10/min. **Idempotency:** required, ≥24h. **Example:** `{"assetId":"01900000-0000-7000-8000-000000000301","sourceVersionId":"01900000-0000-7000-8000-000000000302","modelId":"01900000-0000-7000-8000-000000000303","scope":"headline","parameters":{"count":3}}` → `{"success":true,"message":"Generation accepted.","data":{"id":"01900000-0000-7000-8000-000000000304","type":"generation","status":"queued","resourceType":"content","resourceId":"01900000-0000-7000-8000-000000000301","createdAt":"2026-08-02T12:00:00Z","updatedAt":"2026-08-02T12:00:00Z"},"meta":{"requestId":"req_gen"}}`. |
| `regenerateContent` | **Purpose:** generate a new candidate from identified content. **Route:** `POST /api/v1/content/regenerate`. **Auth/permission:** `content:generate`. **Headers:** bearer, workspace, JSON, required idempotency key. **Path/query:** none. **Body:** `RegenerationRequest`, explicitly including required `contentId`; source version/model/scope required as defined. **Response:** `202 Success<Operation>` plus `Location`. **Validation/status/errors/rate/idempotency:** same as generation; content and source must be related. **Example:** `{"contentId":"01900000-0000-7000-8000-000000000301","sourceVersionId":"01900000-0000-7000-8000-000000000302","modelId":"01900000-0000-7000-8000-000000000303","scope":"tone","parameters":{"tone":"concise"}}` → accepted generation operation.                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `listContent`       | **Purpose:** list current content projections. **Route:** `GET /api/v1/content`. **Auth/permission:** `content:read`. **Headers:** bearer, workspace. **Query:** cursor/common ranges; `q`; repeated `lifecycleStatus`, `origin`; `assetType`, `ownerId`; sort `updatedAt,createdAt,title` default `-updatedAt`. **Body:** none. **Response:** `200 PagedResponse<Content>`. **Validation:** allowlists, UUIDs, cursor fingerprint. **Statuses/errors:** `200`; standard. **Rate:** read 120/min. **Idempotency:** inherent. **Example:** `?lifecycleStatus=draft&limit=25` → paged content envelope.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `getContent`        | **Purpose:** retrieve current content projection and version identity. **Route:** `GET /api/v1/content/{id}`. **Auth/permission:** `content:read`. **Headers:** bearer, workspace, optional conditional ETag. **Path:** UUID. **Query/body:** none. **Response:** `200 Success<Content>` with `ETag`, or `304`. **Validation:** active tenant-safe lookup. **Statuses/errors:** `200`, `304`; standard. **Rate:** read 120/min. **Idempotency:** inherent. **Example:** `GET .../content/019...301` → success Content envelope.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `updateContent`     | **Purpose:** update mutable draft/title/metadata and create a user-origin version when committed. **Route:** `PATCH /api/v1/content/{id}`. **Auth/permission:** `content:write`. **Headers:** bearer, workspace, JSON, required `If-Match`. **Path:** UUID. **Query:** none. **Body:** nonempty subset `{title:string(1..300),bodyText?:string                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | null,bodyRich?:object                                                                                                                                                                              | null,metadata?:object,summary?:string                                                                                                                                                                                                                                                                                        | null,lifecycleStatus?:"draft" | "active"}`; `bodyText`and`bodyRich`cannot both be absent when replacing body. **Response:**`200 Success<Content>`and ETag. **Validation:** body/metadata size, valid transition, unknown fields rejected. **Statuses/errors:**`200`; standard plus version/state conflicts. **Rate:** write 60/min. **Idempotency:** identical PATCH/version is idempotent. **Example:** `{"title":"Revised launch","bodyText":"Updated copy."}` → updated Content version. |
| `deleteContent`     | **Purpose:** soft-delete aggregate content while retaining immutable/evidence records. **Route:** `DELETE /api/v1/content/{id}`. **Auth/permission:** `content:delete`. **Headers:** bearer, workspace, `If-Match`. **Path:** UUID. **Query/body:** none. **Response:** `204`. **Validation:** latest version, hold/publishing rules. **Statuses/errors:** `204`; standard plus conflicts. **Rate:** write 60/min. **Idempotency:** semantic. **Example:** delete with matching ETag → `204`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `duplicateContent`  | **Purpose:** create an independent draft derived from current immutable version. **Route:** `POST /api/v1/content/{id}/duplicate`. **Auth/permission:** `content:write`. **Headers:** bearer, workspace, JSON, required idempotency key. **Path:** UUID. **Query:** none. **Body:** `{title?:string(1..300),projectId?:Uuid                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | null,folderId?:Uuid                                                                                                                                                                                | null}`. **Response:** `201 Success<Content>`with`Location`. **Validation:** source readable/active and destinations tenant-safe. **Statuses/errors:** `201`; standard plus idempotency conflict. **Rate:** write 60/min. **Idempotency:** required. **Example:** `{"title":"Launch copy"}` → created draft Content envelope. |
| `archiveContent`    | **Purpose:** transition active/draft content to `archived`. **Route:** `POST /api/v1/content/{id}/archive`. **Auth/permission:** `content:write`. **Headers:** bearer, workspace, `If-Match`; no idempotency key. **Path:** UUID. **Query/body:** none. **Response:** `200 Success<Content>` with ETag. **Validation:** transition permitted; archive does not delete versions. **Statuses/errors:** `200`; standard plus `409 state_transition_invalid                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | version_conflict`. **Rate:** write 60/min. **Idempotency:** semantic; already archived returns current `200`. **Example:** archive with `If-Match: "5"`→ Content with`lifecycleStatus:"archived"`. |
