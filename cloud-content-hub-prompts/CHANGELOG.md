# Changelog

All notable changes to the Cloud Content Hub Prompt Library are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and prompt packages follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Repository foundation (Phase 1)
- Prompt metadata JSON Schema (`schemas/prompt-metadata.schema.json`)
- Input variable JSON Schema wrapper (`schemas/prompt-input.schema.json`)
- Evaluation case and suite JSON Schemas
- Documentation: standards, naming conventions, versioning, evaluation framework, architecture overview
- Architecture Decision Record ADR-0001 (prompt library foundation)
- Example prompt package: `prompts/_examples/greeting/`
- Local validation script and GitHub Actions workflow
- Contribution guidelines and pull request template

## [0.1.0] - 2026-08-03

### Added

- Initial repository scaffold — standards and structure only, no production prompts
